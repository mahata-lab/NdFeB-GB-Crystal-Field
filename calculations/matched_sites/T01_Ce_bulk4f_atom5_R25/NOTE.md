# T01 (Ce, bulk 4f, atom 5) - no 4f^1 solution

In step 1 the SA-CASSCF in the point-charge field rotates one active orbital into Ce 6s character for every starting guess tried,
so AILFT cannot be applied. A CASCI on the free-ion orbitals (T18) was tested as a substitute but deviates strongly from
SA-CASSCF where both are available (T20-T22, Supplementary Table S6). Ce is therefore reported only for the 4g pair.
