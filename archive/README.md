# Historical material

`previous-figures/`, `previous-tables/` and `previous-scripts/` preserve the version formerly at the repository root. They may contain obsolete table numbers, LF-CI reconstructions, inferred directions, old embedding claims and a one-dimensional nucleation mapping. They are not the figures, tables, or interpretation used in the current manuscript. Use the root README and current `analysis/scripts/reproduce.py` instead.

Original calculation inputs remain in their stable paths under `calculations/`. The current run index labels unrelaxed substitution and mid-grain/site explorations as `exploratory_not_used`. Their parsed numerical data remain available for provenance and the full coefficient archive. Preserving a result does not imply it supports a current manuscript claim.
